# Silero TTS v5 для SUB/WAVE

Небольшая HTTP-прослойка между Silero TTS v5 (русский) и SUB/WAVE. Silero v5_ru
молча вырезает латиницу и цифры, поэтому сервер перед синтезом транслитерирует
английские слова в кириллицу и раскладывает числа, дроби и даты в русские слова.
В итоге один WAV содержит и русскую речь, и английские названия, и цифры.

Работает внутри Docker как часть сети host.docker и подключается к SUB/WAVE через
движок Remote, например:

```
http://host.docker.internal:5001
```

Но можно использовать и просто как standalone-эндпоинт для озвучивания текстов.

## Возможности

- Русский синтез Silero v5, голоса: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`.
- Автоударения и омографы (`put_accent`, `put_yo`, `put_stress_homo`, `put_yo_homo`).
- Транслитерация английских слов и названий в кириллицу.
- Раскладка цифр, дробей и дат в русские слова.
- Контракт SUB/WAVE Remote: `GET /health` и `POST /speak`.

## API

- `GET /health` (и `/healthprobe`) -> `{"ok": true}`
- `POST /speak` `{"text": "...", "voice": "..."}` -> `200` + WAV в теле ответа

Голос в `voice` пробрасывается как есть: если он совпадает с одним из голосов Silero,
используется он; иначе берётся `TTS_DEFAULT_VOICE`, а в ответ добавляются заголовки
`X-TTS-Fell-Back`, `X-TTS-Voice-Used`, `X-TTS-Fell-Back-Reason`.

## Запуск

```bash
cd silero
cp .env.example .env    # при необходимости поправь порт/голос
docker compose up -d --build
```

Первый build скачивает файлы Silero (~140 МБ) и запекает их в образ, поэтому холодный
старт быстрый и повторного скачивания нет. Образ включает CPU-версию torch.

Проверка:

```bash
curl http://localhost:5001/health
curl -X POST http://localhost:5001/speak \
     -H "Content-Type: application/json" \
     -d '{"text": "Привет, мир!", "voice": "xenia"}' \
     --output out.wav
```

## Подключение SUB/WAVE

`Admin -> Settings -> Voices -> Default engine -> Remote`, в поле **Server URL** указать:

```
http://host.docker.internal:5001
```

`127.0.0.1` использовать нельзя, это loopback контейнера контроллера. Либо LAN-IP
машины, на которой крутится сервис: `http://192.168.x.x:5001`.

## Standalone-использование

Сервер ни к чему не привязан и может озвучивать тексты сам по себе:

```bash
curl -X POST http://localhost:5001/speak \
     -H "Content-Type: application/json" \
     -d '{"text": "Сегодня 12.05.2025, играет Nirvana.", "voice": "xenia"}' \
     --output speech.wav
```

## Настройки (env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TTS_PORT` | `5001` | Порт на хосте |
| `TTS_DEFAULT_VOICE` | `xenia` | Fallback-голос |
| `TTS_SAMPLE_RATE` | `48000` | Sample rate WAV |
| `TTS_NUM_THREADS` | `0` | Потоков CPU (0 = все) |
| `TTS_TRANSLIT` | `0` | Транслитерация латиницы в кириллицу (0/1) |
| `TTS_NUM2TEXT` | `0` | Раскладка цифр, дробей и дат в слова (0/1) |

## Транслитерация латиницы

Silero v5_ru молча вырезает латинские буквы, поэтому английские названия песен
превращаются в тишину. Включи `TTS_TRANSLIT=1`, и сервер будет транслитерировать
латинские слова в кириллицу перед синтезом: `Nirvana -> Нирвана`, `The Weeknd -> Зэ Уикнд`.

Ходовые слова берутся из словаря `translit.py` (`OVERRIDES`), остальное проходит через
буквенно-фонетическую таблицу. Качество приблизительное, но название прозвучит
узнаваемо, а не пропадёт.

## Раскладка цифр и дат

Silero v5_ru не читает цифры, число просто выпадает из аудио. Включи `TTS_NUM2TEXT=1`,
и числа будут раскладываться в русские слова:

- `24 -> двадцать четыре`
- `2026 год -> две тысячи двадцать шестой год`
- `36,6 -> тридцать шесть целых шесть десятых`
- `12.05.2025 -> двенадцатое мая две тысячи двадцать пятого года`

Реализация в `num2text.py`.
